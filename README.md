# es-signature-assets

Public images for the Effortless Sleep™ email signature generator
(https://signature-hub.vercel.app/es-signature), served through jsDelivr.

This repo must stay PUBLIC: jsDelivr only serves public repos, and a private
one returns 404, which breaks every image in sent signatures. The full brand kit
stays private in depasen/es-brand-assets; only signature images live here.
Teammate headshots uploaded by the generator land here as es-headshot-<name>-<stamp>.jpg.
